# Optimización de stock y estrategia de compras industriales (MRO)

Este repositorio contiene los archivos de un proyecto desarrollado en un entorno corporativo real para la gestión cuantitativa de inventario y aprovisionamiento industrial. 

El objetivo principal fue transformar la operativa de un almacén tradicional en un modelo predictivo 'just-in-time' para repuestos de mantenimiento correctivo y preventivo.

### Sobre los archivos adjuntos:

* **Script de código:** El archivo subido es una muestra del trabajo desarrollado. Incluyen la lógica analítica para la clasificación ABC-XYZ, el tratamiento estadístico de tiempos de entrega y la automatización de los niveles de reorden.
* **Documentación explicativa:** Se incluyen documentos que detallan la metodología matemática y de negocio empleada, así como el impacto del modelo en la eficiencia del almacén.
